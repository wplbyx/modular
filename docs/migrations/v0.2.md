# Migrating to modular v0.2

v0.2 intentionally removes compatibility globals and changes infrastructure configuration.

## Resource injection

Replace `GetDB`, `GetClient`, and package-level HTTP helpers with constructor injection. Managed resources implement both `core.Resource` and `core.Provider[T]`:

```go
dbResource := gormpostgres.NewResource(&cfg.Database)
repo := repository.NewRepository(dbResource)

application, err := app.NewApplication(ctx, &cfg.Application,
    app.WithResource(dbResource),
    app.WithEndpoint(httpServer),
)
```

Repository methods call `provider.Value()` after Application has completed Setup. Migrations that must run during startup can use `core.NewFuncResource` and should depend on the same Provider.

## Configuration

- Replace `configitem.Database.Dsn`, host, port, username, and password fields with one explicit `configitem.Database.DSN`.
- Select a GORM package in cmd: `gorm/postgres`, `gorm/mysql`, `gorm/clickhouse`, or `gorm/sqlite`.
- Replace Mongo use of `configitem.Database` with `configitem.Mongo` and `URI` or `Hosts`.
- Embedded defaults can use `config.WithConfigFS(fsys, "config.yaml")`.

## Removed symbols

- Bun/GORM: `GetDB`
- Mongo/Redis: `GetClient`
- Bun: `NewBunMigration`; pass a DB to `NewMigrationTool`
- HTTP client: `Init`, `GetClient`, and package-level Get/Post/Download helpers
- Errors: `CustomError`, `CustomErrorOption`, `WithCode`, and `WithMsgf`

## Application

- A registrar without a ServiceNode now fails in `NewApplication`.
- Run is single-use and duplicate calls return `app.ErrApplicationAlreadyRun`.
- Close before Run permanently closes that Application without starting or stopping dependencies.
- `app.WithLogger` provides an explicit zap logger while the existing logging facade remains the default.

## HTTP

- `httpclient.NewClient` returns `*httpclient.Client`; use `Do` as the primary interface.
- POST/PATCH retries require `Idempotency-Key` or a custom retry policy.
- Add readiness with `httpserver.WithReadiness`; `/health` remains liveness.
- Use `httpserver.NoWriteTimeout` for SSE or other streaming responses.

## Errors and localization

The v0.2 error interface uses HTTP status codes plus a stable reason. Replace the old option-only constructor:

```go
// v0.1
errs.New(errs.WithCode(530), errs.WithMsgf("user %s not found", id))

// v0.2
var UserNotFound = errs.Define(
	"USER_NOT_FOUND",
	errs.Template("user %v not found", errs.Name("user_id")),
)
errs.NotFound(UserNotFound.With("user_id", id), errs.WithCause(cause))
```

Code templates only support `%v` slots and `%%` literal percent signs. Each `%v` maps to the following `errs.Name` in order. Generate one reason-to-template mapping per locale with:

```bash
go install github.com/wplbyx/modular/packages/generate/cmd/err_template_gen@latest
err_template_gen --root . --packages ./internal/user/... --out ./config/user/locales --languages zh-CN,en-US
err_template_gen --root . --out ./config/user/locales --languages zh-CN,en-US --check
```

The generator preserves product copy while strictly validating reason and `{{.name}}` slot contracts. The default locale must define `UNKNOWN`. Load the immutable Catalog at startup, create one `errs.Handler` with the process zap logger, and inject it through `httpserver.WithErrorHandler` and `rpcserver.WithErrorHandler`.

HTTP handlers can use `httpserver.Wrap` to return errors or call `c.Error(err)`. Without an injected error handler, servers retain their previous recovery behavior, but localization and diagnostic projection are disabled.

`Error.Message` and the code template passed to `errs.Template` are public-safe. A missing bound value renders as `UNKNOWN` in that position and is logged as a template error. Put database messages, identifiers not intended for clients, and operational context in the cause or `errs.WithField`; these are logged but never serialized to HTTP or gRPC clients.
