# modular v0.4 Pure Modular Monolith

## Product contract

modular scaffolds one deployable Go Application made of bounded-context
Business Modules. It does not model module extraction or transparent switching
between monolith and microservices.

## Architecture model

- `.modular/architecture.yaml` schema 2 contains one `application` with name,
  transports, ports, and shared resources, plus an acyclic `modules` dependency
  map.
- A Business Module owns its behavior, use cases, public Go contract, and data
  writes. Other modules may import only its `contract` package.
- The Application owns one lifecycle, runtime identity, logger, health manager,
  transport policy, resource set, EventBus, and at most one HTTP/gRPC server.
- `internal/platform/wiring` exposes typed `Platform`, `Resources`, and
  `Assembly`; `WireApplication(platform)` is the user-owned composition root.
- Modules are vertical business slices. App and domain packages appear only
  when their actual behavior justifies them.

## Contracts and consistency

Module contracts are hand-written Go interfaces with Command/Query/Result
types. External adapters map HTTP, gRPC, or event DTOs to those types. modular
does not scaffold proto, Buf, wire DTOs, or contract generators.

Cross-module synchronous dependencies must remain acyclic. A cross-module ACID
workflow belongs to its initiating module, calls only public contracts, and
uses a project-defined transaction interface. Direct access to another
module's implementation, repositories, tables, or raw transaction handles is
invalid.

## Migration

`migrate v0.3-to-v0.4` accepts a v0.3 project only when its architecture has one
Process. It lifts that Process into `application`, removes extraction metadata,
updates managed wiring, and removes unchanged default Buf scaffolds. Customized
external proto/Buf assets are preserved outside modular management. Multiple
Processes, customized legacy business wiring, old generator references, and
`*_modular.pb.go` output stop automatic migration with actionable errors.
